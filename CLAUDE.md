# MeetMinder

Electron desktop app (HTML/CSS/JS interface + Node.js) that records customer meetings, marks key moments and tracks follow-ups. Target platform: macOS; developed on Windows.

Before changing anything, read the project history, decisions, current status and next steps:

@PROJECT_MEMORY.md

When you finish a step, update sections 1, 4 and 7 of PROJECT_MEMORY.md. After code changes, run `npm run zip:mac` so the Mac copy is up to date.
